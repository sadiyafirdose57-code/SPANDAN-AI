# SPANDAN – AI-Powered Time Management System

## Overview
SPANDAN is a productivity and time management web application designed to help users organize daily activities, track tasks, monitor progress and improve time management.

## Features
- Interactive productivity dashboard
- Task creation, completion and deletion
- Task categories and priority management
- Search and task filtering
- Daily productivity statistics
- Progress visualization and weekly activity chart
- Rule-based smart productivity recommendations
- Browser-based task persistence
- Responsive interface for desktop and mobile

## Technology Stack
**Frontend:** React, Vite, CSS, Lucide React, Recharts

**Backend:** Node.js, Express.js, CORS, dotenv

**Storage:** Browser Local Storage

## Run Locally

### Backend
```bash
cd backend
npm install
npm run dev
```
Backend: http://localhost:5000

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173

## Current Implementation Notes
- Tasks are currently persisted in browser Local Storage.
- The backend currently uses in-memory sample data.
- Productivity recommendations are rule-based, not generated by a live AI model.
- Weekly chart values are illustrative sample data.
